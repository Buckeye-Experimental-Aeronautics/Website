Homepage graphics: alternate concepts

The current homepage's subteam band and roadmap timeline are clean but a little generic. These are three alternate treatments for each, pulled from how real student teams actually present the same information — nothing here is live; the homepage is untouched. Pick one (or none) and I'll build it into index.html.

References browsed for this pass: gtsupersonics.com (soft, unpretentious cards, no icons — the "homemade Squarespace" end of the spectrum) and cornellrocketryteam.com/subteams (a blueprint-style exploded diagram with line-art icons on a grid background — the "engineering sketch" end).

A vertical checklist in a monospace "logbook" font — checkbox ticked for the milestone in progress. Reads immediately, scales to any number of milestones, and is the easiest of the six concepts to make genuinely mobile-friendly since it's a list by default.
Concept E — Flight path trail map
ref: national-park trail-map convention, applied to a flight path
A dotted route across graph paper, like a hiking-trail map, with a small plane-icon marker at the flagship milestone. Most visually distinctive of the six, but the curved SVG path needs hand-tuning per milestone count and is the hardest to keep clean at phone width — would likely need a completely different (probably vertical, Concept-D-like) mobile layout rather than shrinking this one.

Recommendation

If you want a steer

B (blueprint) + D (mission log) is the safest pairing — both stay closest to the site's existing engineering-process voice and are the least risky to build responsively. A (patch cards) + F (boarding pass) is the more playful pairing if you want the homepage to feel less corporate. C and E are the highest-personality, highest-risk options — good for a single page, riskier as a system if it needs to repeat elsewhere on the site.
